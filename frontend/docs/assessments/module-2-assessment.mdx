# Module 2 Assessment: Digital Twins with Gazebo & Unity

## Overview
This assessment evaluates your understanding of digital twin technology and simulation environments for robotics. You will demonstrate knowledge of both Gazebo and Unity for robotics applications, including environment creation, sensor simulation, and integration with ROS 2.

## Learning Objectives Covered
- Understanding digital twin concepts and benefits
- Creating simulation environments using Gazebo
- Developing Unity scenes for robotics applications
- Implementing sensor simulation in both environments
- Integrating simulation with ROS 2

## Assessment Structure

### Part A: Multiple Choice Questions (20 points)
Answer the following multiple choice questions. Each question is worth 2 points.

1. What is the primary purpose of a digital twin in robotics?
   a) To replace real robots completely
   b) To provide a virtual representation for testing and validation
   c) To reduce the need for programming
   d) To increase hardware costs

2. Which physics engine is NOT commonly used with Gazebo?
   a) ODE
   b) Bullet
   c) PhysX
   d) Havok

3. What does the ROS# package enable in Unity?
   a) Better graphics rendering
   b) Communication between Unity and ROS/ROS 2
   c) Physics simulation
   d) Audio processing

4. Which of the following is NOT a benefit of simulation in robotics?
   a) Risk-free testing
   b) Accelerated development
   c) Perfect real-world replication
   d) Cost reduction

5. What is the main advantage of domain randomization in simulation?
   a) Reduces computational requirements
   b) Improves visual quality
   c) Creates more robust AI models
   d) Simplifies environment design

6. Which Gazebo component handles visualization and user interaction?
   a) Gazebo Server
   b) Gazebo Client
   c) Gazebo Plugins
   d) Model Database

7. What does "reality gap" refer to in robotics simulation?
   a) The difference between simulated and real-world performance
   b) The physical gap between robots
   c) The time delay in simulation
   d) The cost difference between sim and real

8. Which Unity package is specifically designed for robotics development?
   a) Unity ML-Agents
   b) Unity Robotics Package
   c) Unity XR
   d) Unity Animation

9. What is synthetic data generation in the context of simulation?
   a) Creating artificial training data from simulation
   b) Generating fake sensor data
   c) Creating 3D models
   d) Simulating network delays

10. Which sensor simulation is typically most challenging to make realistic?
    a) Camera
    b) LIDAR
    c) IMU
    d) GPS

### Part B: Short Answer Questions (30 points)
Answer the following questions briefly (2-3 sentences each). Each question is worth 5 points.

1. Explain the concept of a digital twin and its benefits in robotics development.

2. Compare and contrast Gazebo and Unity for robotics simulation. What are the advantages of each?

3. What is the significance of sensor simulation in robotics development? Why is it important for the simulation to be realistic?

4. Describe the process of integrating a Gazebo simulation with ROS 2. What are the key components involved?

5. What is the "reality gap" in robotics simulation and how can it be addressed?

6. Explain how domain randomization helps in developing robust robotic systems.

### Part C: Practical Exercise (50 points)

Create a complete simulation environment that demonstrates the integration of simulation with ROS 2:

1. Create a Gazebo environment with a mobile robot and obstacles (10 points)

2. Implement sensor simulation for the robot (camera and LIDAR) (10 points)

3. Create a Unity scene that replicates the same environment (10 points)

4. Integrate both simulations with ROS 2 using appropriate bridges (10 points)

5. Implement a simple navigation task that can be performed in both simulation environments (10 points)
