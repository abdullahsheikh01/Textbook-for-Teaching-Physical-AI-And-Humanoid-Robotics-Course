# Week 1: Introduction to Physical AI & ROS 2 Fundamentals

## Overview
This week introduces the fundamental concepts of Physical AI and the Robot Operating System (ROS 2), which serves as the nervous system for robotic applications. Students will learn the basics of ROS 2 architecture, nodes, topics, and services.

## Learning Objectives
By the end of this week, students will be able to:
- Define Physical AI and its importance in robotics
- Understand the basic architecture of ROS 2
- Create simple ROS 2 nodes in Python
- Implement publisher-subscriber communication patterns
- Use ROS 2 tools for debugging and monitoring

## Schedule

### Day 1: Introduction to Physical AI
- What is Physical AI?
- The embodied intelligence paradigm
- Applications in humanoid robotics
- Course overview and expectations

### Day 2: ROS 2 Architecture
- Nodes, topics, and services overview
- DDS (Data Distribution Service) concepts
- Client libraries (rclcpp, rclpy)
- Setting up the development environment

### Day 3: Creating ROS 2 Nodes
- Node structure and lifecycle
- Publisher and subscriber implementation
- Message types and custom messages
- Practical exercise: Simple publisher-subscriber

### Day 4: Services and Actions
- Synchronous vs asynchronous communication
- Service implementation
- Action servers and clients
- Practical exercise: Simple service

### Day 5: ROS 2 Tools and Best Practices
- Using ros2 command line tools
- Launch files for system startup
- Debugging and monitoring techniques
- Week review and Q&A

## Assignments
1. **Assignment 1**: Create a ROS 2 package with a publisher and subscriber
2. **Assignment 2**: Implement a simple service for mathematical operations
3. **Assignment 3**: Create a launch file to start multiple nodes
